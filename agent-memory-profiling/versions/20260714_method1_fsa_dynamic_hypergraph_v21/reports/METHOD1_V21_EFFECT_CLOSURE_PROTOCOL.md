# Method 1 v21 Effect Closure Protocol

The core method combines two train-derived relation sources: shared UOT-FSA fuzzy semantic incidence and evidence-bundle co-selection experience. For a multi-group training query, an acceptable bundle contains exactly one alternative member from each evidence group. Members inside one group remain OR alternatives and are never relabeled as jointly required.

The deployable path must learn bundle compatibility across train queries and generate bundle candidates without loading heldout gold groups. It must use sparse activated semantic-edge lists rather than scanning the complete dense eligible-by-prototype incidence. The existing dense QHDS OOF result is retained as a quality reference, not treated as the final efficient implementation.

All methods use one neutral source-order physical memory layout with capacity 16 and actual memory payload bytes. No method-specific or dynamic physical relayout is allowed. The core Gate compares quality at matched candidate, byte, Tile, and latency cost, and cost inside the preregistered plus-or-minus 0.01 quality-equivalence interval. Logical Tile counts and host CPU/GPU latency are reported separately; no PIM latency is estimated.

Component ablations may follow the core effect closure, but ANN flat, dense QHDS reference, sparse joint hypergraph, and a budgeted pairwise factor graph are mandatory core competitors. Calibration and formal test remain locked and unread.
