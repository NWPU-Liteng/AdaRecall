# Motivation v5 Claim Boundaries

## Allowed

- Longer histories increase candidate-processing and traffic pressure.
- Evidence demand can contain multiple groups and alternative memories.
- Flat top-B retrieval can leave groups uncovered or use capacity redundantly.
- Chronological placement can scatter useful memories and increase Tile activation.
- Content insertion makes full index rebuild work grow with corpus size.
- A generic append-only index can maintain exact lookup results while touching only
  newly inserted postings in this maintenance stress test.

## Forbidden

- Hypergraph, FSA, QESA, QHDS, or persona-shard superiority.
- Any Agent answer-quality, reasoning-stage, access-order, co-access, or future
  transfer claim.
- PIM hardware latency, energy, or speedup.
- Treating oracle Tile packing as an implemented layout.
- Treating deterministic chronological insertion as a causal Agent stream.
