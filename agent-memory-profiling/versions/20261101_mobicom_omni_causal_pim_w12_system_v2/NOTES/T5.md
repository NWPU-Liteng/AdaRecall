# Phase 5 实验运行记录

## 冻结范围

- 数据：`pilot112_v1`，8 个用户、112 道题；只含 development 与 validation，
  不含 holdout。
- prepared、cohort、locator 与 index 固定复用 v1 的
  `artifacts/full_experiment_20261030` 与
  `artifacts/subsets/pilot112_v1`。
- Reader 使用 GPU `0,1,3,5`，Judge 使用 GPU `6`；不使用 GPU `2,4`。
- 每个 Reader 实测占用约 `17.8 GiB`，同一 GPU 不并行第二个 Reader。
- calibrator 只用 `v2_asof_op` 的 development candidate dump 拟合；
  validation 只用于报告指标，fit 脚本不读取 validation dump。

`candidate_dump`，防止跨臂覆盖。

## 执行门禁

1. `v2_asof_op` 先完成 development 用户 `0..3`，并确认每用户 14 题输出完整。
2. 用 `fit_calibration.py` 生成 `results/v2_asof_op/calibrator.json`，记录文件
   SHA-256；任何 conformal 或 noisy-or 配置必须引用该 path/hash。
3. 七份配置全部通过 `load_config()` 与 `load_extensions()` 后才允许进入后续臂。
4. `v2_asof_op` 再完成 validation 用户 `4..7`；其余臂按矩阵顺序逐臂运行。
5. 每臂只在该臂全部输出完成后执行 postprocess，避免把 partial 结果计入报告。

## 每臂后处理

- `scripts/report_run_stats.py <run_dir>`
- `scripts/eval_evidence_recall.py <run_dir> --labels ... --index-root ...`
- `scripts/judge_incremental.py --config <config>`
- `scripts/pim_replay.py <trace_dir> <stats_dir>`（仅 shadow 臂）
- conformal 臂另跑 `scripts/eval_conformal_coverage.py`，只读取 validation dump。

## 报告边界

- 所有效果指标只在 validation split 报告；development 仅用于校准和运行健康检查。
- 当前 Judge 是固定的本地 Qwen3-VL-8B-Instruct proxy，不表述为官方
  Qwen3-14B 分数。
- 未实际完成的 latency、energy 或 speedup 不写成实测结论；PIM 回放数值必须带
  模型来源与 `params_missing`/代理字段说明。
- 真机实验不在本轮范围内；T4.3 只保留可复现脚手架。

## W12 续跑修复

- `layout_instance_sha256` 是进程内对象身份；断点续跑会生成新值，旧汇总误把两个
  进程实例判为布局漂移，导致 user 0–3 在全部推理完成后收尾失败。
- 新增跨进程稳定的 `layout_spec_sha256`，覆盖模块名、别名关系、layout inventory、
  packed storage、group scales 与 bias；同一内容在不同进程应相等，内容变化必须拒绝。
- 汇总按请求检查三阶段实例与 spec 一致；跨请求允许进程实例不同，但所有已记录的
  内容 spec 必须一致。旧 checkpoint 没有 spec 时记为
  `layout_spec_complete=false`，不伪造稳定摘要。
- `all_requests_all_stages_hit_bank` 改为只检查适用阶段；
  `not_applicable_contextual` 的 `source_grounding` 不计为漏命中。原始全阶段命中
  保留在 `all_requests_all_raw_stages_hit_bank`。
- 定向 W12/candidate 测试 `25 passed`；完整 CPU 回归 `822 passed, 3 failed`。
  三个失败均为已知基线，不属于本次改动：
  `test_hyperpim_sc_projection::test_calibration_reads_generated_token_profile`、
  `test_main_experiment_contract::test_evaluation_reports_missing_judge_without_substitution`、
  `test_proof_direction::test_shared_query_span_does_not_merge_distinct_event_reference_roles`。
