# T0.3 接口理解

- 主配置由 `run_main_experiment.load_config()` 读取；每个用户由 `serve_one()` 启动独立的
  `run_proof_mainline.py` worker。worker 通过命令行接收配置，因此扩展块以规范 JSON 传给
  worker，并由 worker 在参数解析后立即调用 `load_extensions()` 重建冻结 dataclass。
- `run_proof_mainline.py` 的题级结果位于 `rows`，用户级元数据位于输出 JSON 顶层；partial
  checkpoint 也是用户级输出。完整输出和 partial 都应携带同一扩展契约，避免恢复时混用配置。
- `Extensions` 输出契约采用 `{"config": <extensions values>, "sha256": <canonical JSON hash>}`。
  canonical JSON 使用稳定键排序、无多余空白和 UTF-8，哈希覆盖该字节串。
- `regression_check.py` 当前只选择计划要求的回归字段，本身不会比较 `extensions`。为避免未来
  扩展 COMPARE_FIELDS 时误比较，增加显式 `IGNORED_FIELDS = ("extensions",)`。
- v1/v2 默认行为必须一致：所有新增配置开关使用第 2 部分默认值；当前任务不启用任何新路径。
