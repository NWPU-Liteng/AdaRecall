# T3.2 校准器拟合

## 实现

- 新增 `scripts/fit_calibration.py`，CLI 为
  `--dump <dir> --labels <path> --out <calibrator.json>`，并支持可选的
  `--index-root`。只接受 `split=development` 的 candidate dump；其他 split、
  非 48 宽度、重复题目或缺失 label 都 fail closed。
- 正样本按题目标签判定：候选 `session_ids` 与 `source_session_ids` 有交集，或候选
  image object 的 `source_sha256` 等于 `evidence_image_refs` 经 T1.3 source mapping
  得到的 sha256。text 与 image 分别拟合
  `IsotonicRegression(increasing=True, out_of_bounds="clip")`，概率裁剪到
  `[1e-4, 1-1e-4]`。
- 对每题合并所有 demand 的 48 候选池，按标注 session/image 单元计算
  `g_q = min_e max(rerank_score)`。任一标注单元无匹配候选，或图片标签无法映射时，
  `g_q=-inf`。没有标注证据单元的题目不进入保形阈值样本，并单独计数。
- 对每个 `alpha in {0.05,0.1,0.2}` 使用第 `floor(alpha*(n+1))` 个升序 `g_q`
  （1-based）；序号小于 1 时阈值为 `-inf`。JSON 无法原样表达负无穷，因此 `tau`
  中的 `null` 明确定义为 `-inf`，并通过 `tau_negative_infinity` 再次列出。
- calibrator 保存 text/image 断点、`tau` 表、10 箱可靠性表、ECE、题目数、候选数、
  `g_q=-inf` 比例、使用的 user 列表和输入文件摘要。顶层 `sha256` 对不含自身
  `sha256` 字段的规范化 JSON payload 计算；加载时可调用
  `validate_calibrator()` 重算校验。
- 覆盖说明只使用指定表述：
  “覆盖保证以问题可交换为前提，且只针对 48 个候选池。”

## 测试

- 定向测试：`pytest -q tests/test_fit_calibration.py`，结果 `6 passed`。
- 覆盖 session/image 两类正样本、按 modality 分离拟合、缺失证据单元导致
  `-inf`、alpha 索引与小 n 的 `-inf`、概率两端裁剪、非 development split
  拒绝、确定性输出及 sha256 篡改检测。
- 完整 CPU：`pytest -q tests -m "not gpu"`，结果 `786 passed, 3 failed`。
  三个失败仍是既有基线：缺少 `artifacts/hyperpim_sc_trace_v1`、旧 judge 状态
  字符串、重复 demand 预期差异。

## 真实数据运行

- 输入为 T3.1 单题 dump
  `regression/golden_v2_t31_dump/candidates/1/1_q_104.json`，输出为
  `regression/golden_v2_t32_calibrator/calibrator.json`。
- 使用 user `1`，1 道 development 题，2 个 demand。校准候选共 96 个：
  text 92 个（16 正）、image 4 个（0 正）。text ECE 为
  `3.2608695653968976e-06`，image ECE 为 `1e-4`。
- 唯一题目的标注 session `1_52_1` 在候选池中命中，但标注图片 sha256
  `602f36c129140f893aad385b19711ee3f3129fa93dd3a3b4e477ccc017f96de0`
  未进入候选池，因此 `g_q=-inf`、`g_q=-inf` 比例为 `1.0`。
- 保形样本数 `n=1`。三个 alpha 的 `floor(alpha*(n+1))` 都小于 1，所以三个
  `tau` 均为 `-inf`。该单题样本不足以形成有限阈值，不补造数据，也不报告覆盖率。
- 产物 `sha256` 为
  `5a93c55dbc07c8676f33ba116d124523c8b91ac55d67df64b86a3220336f497f`；
  重复运行生成的文件逐字节一致。

## 边界

- 本任务是 eval-only 离线拟合，serving 不导入该脚本，也不改变默认候选策略。
- 当前结果只证明实现符合 T3.2 公式；单题运行无法支持任何覆盖率或泛化结论。
