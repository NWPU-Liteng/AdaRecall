# T0.2 接口理解

- Serving 文件范围按计划为：`scripts/run_proof_mainline.py`、
  `scripts/run_main_experiment.py`、全部 `scripts/omni_proof_*.py` 以及
  `pim_backend/*.py`。当前源码扫描未发现 `labels.jsonl`、`golden_answers`、
  `"question_type"` 或 `"difficulty"`，因此静态隔离测试不需要白名单。
- `run_proof_mainline.py` 的入口是 `main()`；参数解析后才会读取 prepared、cohort、
  index 等文件。运行时守卫应在 `main()` 的第一条语句安装，确保任何后续标签文件打开
  都会被拒绝。
- 计划明确要求包装 `builtins.open`。现有代码中另有 `Path.open()`/`Path.read_text()`；
  这些不是本次包装范围，不能为了扩大守卫范围擅自修改既有读取接口。
- 守卫只拦截路径字符串、`bytes` 路径或 `os.PathLike` 且规范化后以
  `labels.jsonl` 结尾的请求；文件描述符等非路径参数应透传给原始 `open`。
- 当前 `tests/` 尚无 `conftest.py`，也没有注册 `gpu` marker。
